Armor Catalog Gallery Setup

Install the local userscript in the browser where you are logged into Nexus Mods. After it is installed, open the catalog preview and use the fixed Harvest Nexus galleries button.

Install

Tampermonkey or Violentmonkey should open an install screen when you click the userscript.

Install gallery harvester Open catalog preview

Use

  1. Make sure this same browser is logged into Nexus Mods.
  2. Open the catalog preview at http://127.0.0.1:4173/.
  3. Click Harvest Nexus galleries.
  4. Save the downloaded file as armor-catalog/data/nexus-gallery-candidates.csv.
  5. Tell Codex to import it, then we can do the visual pass together.
