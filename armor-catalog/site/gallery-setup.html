Armor Catalog Gallery Setup

Install the local userscript in the browser where you are logged into Nexus Mods. After it is installed, open the catalog preview and use the fixed Harvest Nexus galleries button.

Install

If Chrome blocks direct install from localhost, use the manual install flow below.

Try direct install Open catalog preview

Manual Install

  1. Install or open Tampermonkey/Violentmonkey in this browser.
  2. Open its dashboard and create a new script.
  3. Click Copy script below, paste over the starter script, and save.
  4. Make sure the script toggle is enabled in the dashboard.
  5. Refresh the catalog preview. You should see Gallery harvester loaded and the Harvest Nexus galleries button.
Open raw script

Use

  1. Make sure this same browser is logged into Nexus Mods.
  2. Open the catalog preview at http://127.0.0.1:4174/.
  3. If Tampermonkey says the script has not run, check that the script is enabled and that Tampermonkey has site access for 127.0.0.1.
  4. Click Harvest Nexus galleries.
  5. Save the downloaded file as armor-catalog/data/nexus-gallery-candidates.csv.
  6. Tell Codex to import it, then we can do the visual pass together.
